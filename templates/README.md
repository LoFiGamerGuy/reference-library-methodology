# Templates

Schema templates for the files that make up a reference library. Copy these into your library and fill in your content.

| Template | Goes in | Purpose |
|----------|---------|---------|
| [`book-frontmatter.template.md`](./book-frontmatter.template.md) | `<library>/<category>/<book-slug>/content.md` | YAML frontmatter for a book entry |
| [`INSIGHTS.template.md`](./INSIGHTS.template.md) | `<library>/<category>/<book-slug>/INSIGHTS.md` | Distilled non-obvious patterns from a book |
| [`synthesis-doc.template.md`](./synthesis-doc.template.md) | `<library>/_synthesis/<topic>-patterns.md` | Cross-book patterns on a topic |
| [`project-map.template.md`](./project-map.template.md) | `<library>/_maps/<project-slug>.md` | Tier-ranked reading list for a project |
| [`inventory.template.md`](./inventory.template.md) | `<library>/INVENTORY.md` | Top-level catalog of the library (auto-generated by `tools/regenerate_inventory.py`) |
| [`tagging-config.template.json`](./tagging-config.template.json) | (anywhere — config for `tools/tag_library.py`) | Maps categories and book slugs to project tags |

## How to use these

1. **Set up your library directory** outside this repo (your books are yours; the methodology repo is generic).
2. **For each book you add**, create `<library>/<category>/<book-slug>/content.md` and start with the frontmatter template at the top.
3. **After extracting INSIGHTS** (via `batch_extract_insights.py`), the INSIGHTS.md file is auto-generated using a similar pattern. Refine it manually as you read the book.
4. **For each project you work on**, create `<library>/_maps/<project-slug>.md` with a tier-ranked list of relevant books. The map drives the session quick-start tool.
5. **For cross-cutting patterns**, create `<library>/_synthesis/<topic>-patterns.md` distilling what multiple books say on the topic.

See [`docs/library-structure.md`](../docs/library-structure.md) for the full directory layout.

## Why YAML frontmatter

The frontmatter is what the tools query. Keeping it lightweight and consistent across files is the load-bearing convention. See [`docs/library-structure.md`](../docs/library-structure.md) for the schema.
